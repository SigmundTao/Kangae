Kangae

write freely

Go to app

Notes:

Create, write, save, duplicate and delete notes.

Search:

Search for any text in a note title or body.

Quick Capture:

Stash away any ideas without breaking your attention

Tools:

Use the Pomodoro timer, To do list or Flashcards in the sidebar or expand them as a tab.

Markdown:

Toggle betwenen edit mode and preview mode. Most common markdown is supported as well as a few I created myself

Export:

Export your entire note vault as a zip file to have a back up or to use the notes natively.

Daily Notes:

Create a note for today at the press of a button, create your own preset and have them create in a specified folder
